4. प्राथमिकता A अध्याय — सिद्धांत, सूत्र, हल किए गए उदाहरण

4.1 दो चरों वाले रैखिक समीकरण युग्म

महत्त्वपूर्ण टॉपिक

  • रैखिक समीकरण युग्म का आलेखीय निरूपण
  • प्रतिस्थापन विधि, विलोपन विधि, वज्र-गुणन विधि
  • संगत/असंगत युग्म, हलों की संख्या की शर्तें

सरल हिंदी में अवधारणा

दो चरों वाले दो रैखिक समीकरण मिलकर एक युग्म बनाते हैं। इनका हल वह बिंदु होता है जहाँ दोनों समीकरणों की रेखाएँ एक-दूसरे को काटती हैं।

स्थितिशर्तहल
प्रतिच्छेदी रेखाएँa₁/a₂ ≠ b₁/b₂एक अद्वितीय हल (संगत)
समांतर रेखाएँa₁/a₂ = b₁/b₂ ≠ c₁/c₂कोई हल नहीं (असंगत)
संपाती रेखाएँa₁/a₂ = b₁/b₂ = c₁/c₂अनंत हल (संगत)
📦 रैखिक समीकरण युग्म के सूत्र
a₁x + b₁y + c₁ = 0 और a₂x + b₂y + c₂ = 0
प्रतिच्छेदी: a₁/a₂ ≠ b₁/b₂
समांतर: a₁/a₂ = b₁/b₂ ≠ c₁/c₂
संपाती: a₁/a₂ = b₁/b₂ = c₁/c₂

हल किए गए उदाहरण

उदाहरण 1 (आसान): जाँचें कि x + 2y + 3 = 0 और 3x + 6y + 9 = 0 के कितने हल हैं।

हल: a₁=1, b₁=2, c₁=3; a₂=3, b₂=6, c₂=9
a₁/a₂ = 1/3, b₁/b₂ = 2/6 = 1/3, c₁/c₂ = 3/9 = 1/3
तीनों अनुपात बराबर → संपाती रेखाएँ → अनंत हल।

उदाहरण 2 (मध्यम): विलोपन विधि से हल करें: 2x + 3y = 11, 2x - 4y = -24

हल: (2x+3y) - (2x-4y) = 11-(-24) → 7y = 35 → y = 5
y=5 रखने पर: 2x + 15 = 11 → 2x = -4 → x = -2
उत्तर: x = -2, y = 5

उदाहरण 3 (परीक्षा-स्तर): 5 पेंसिल और 7 कलम का मूल्य ₹50 है तथा 7 पेंसिल और 5 कलम का मूल्य ₹46 है। प्रत्येक का मूल्य ज्ञात करें।

हल: 5x + 7y = 50 …(1); 7x + 5y = 46 …(2)
(1)×5: 25x + 35y = 250; (2)×7: 49x + 35y = 322
घटाने पर: 24x = 72 → x = 3; 15 + 7y = 50 → y = 5
पेंसिल ₹3, कलम ₹5

✅ स्वयं जाँच चेकलिस्ट

4.2 द्विघात समीकरण

महत्त्वपूर्ण टॉपिक

  • द्विघात समीकरण का मानक रूप
  • गुणनखंड विधि, पूर्ण वर्ग विधि, द्विघात सूत्र
  • विविक्तकर (D) और मूलों की प्रकृति
  • मूलों का योग और गुणनफल
📦 द्विघात समीकरण के सूत्र
मानक रूप: ax² + bx + c = 0
द्विघात सूत्र: x = (-b ± √(b²-4ac)) / 2a
विविक्तकर: D = b² - 4ac
D > 0 → दो भिन्न वास्तविक मूल
D = 0 → दो बराबर वास्तविक मूल
D < 0 → कोई वास्तविक मूल नहीं
मूलों का योग: α + β = -b/a
मूलों का गुणनफल: αβ = c/a

हल किए गए उदाहरण

उदाहरण 1: 2x² - 5x + 3 = 0 को गुणनखंड विधि से हल करें।

हल: 2×3 = 6; -2 और -3 से योग -5
2x² - 2x - 3x + 3 = 0 → (2x-3)(x-1) = 0
x = 3/2 या x = 1

उदाहरण 2: द्विघात सूत्र से हल करें: x² + 4x - 5 = 0

हल: a=1, b=4, c=-5; D = 16 + 20 = 36
x = (-4 ± 6)/2 → x = 1 या x = -5

उदाहरण 3: ऐसी दो क्रमागत धन पूर्ण संख्याएँ ज्ञात करें जिनके वर्गों का योग 365 हो।

हल: x² + (x+1)² = 365 → 2x² + 2x - 364 = 0 → x² + x - 182 = 0
D = 1 + 728 = 729; x = (-1 ± 27)/2 → x = 13 या -14
संख्याएँ: 13 और 14

4.3 समान्तर श्रेढ़ी (AP)

📦 समान्तर श्रेढ़ी के सूत्र
nवाँ पद: aₙ = a + (n-1)d
n पदों का योग: Sₙ = n/2 [2a + (n-1)d]
यदि अंतिम पद l हो: Sₙ = n/2 [a + l]

हल किए गए उदाहरण

उदाहरण 1: AP: 5, 8, 11, ... का 12वाँ पद ज्ञात करें।
हल: a=5, d=3; a₁₂ = 5 + 11×3 = 38

उदाहरण 2: AP: 7, 13, 19, ... का 20 पदों तक योग ज्ञात करें।
हल: S₂₀ = 20/2 [2×7 + 19×6] = 10[14+114] = 1280

उदाहरण 3: AP का 5वाँ पद 11 और d=2 है। प्रथम पद ज्ञात करें।
हल: a + 4×2 = 11 → a = 3

4.4 बहुपद

📦 बहुपद के सूत्र
ax² + bx + c के शून्यक α, β के लिए:
α + β = -b/a, αβ = c/a
विभाजन एल्गोरिथ्म: भाज्य = भाजक × भागफल + शेषफल

हल किए गए उदाहरण

उदाहरण 1: 7u⁶ - (3/2)u⁴ + 4u² + u - 8 की घात क्या है? उत्तर: 6

उदाहरण 2: यदि p(x) का एक शून्यक 2 है, तो कौन गुणनखंड है? उत्तर: x-2

उदाहरण 3: x² - 5x + 6 के शून्यक ज्ञात करें।
हल: (x-2)(x-3) → शून्यक 2, 3; योग 5 = -(-5)/1; गुणनफल 6 = 6/1 ✓

4.5 त्रिभुज

📦 त्रिभुज के सूत्र
थेल्स प्रमेय: यदि DE || BC, तो AD/DB = AE/EC
पाइथागोरस: (कर्ण)² = (लंब)² + (आधार)²
समरूप त्रिभुजों के क्षेत्रफलों का अनुपात = संगत भुजाओं के वर्गों का अनुपात

हल किए गए उदाहरण

उदाहरण 1: त्रिभुज ABC में AD, ∠BAC का अर्द्धक है। AB=10, AC=14, BC=6 सेमी। DC ज्ञात करें।
हल: BD/DC = AB/AC; (6-x)/x = 10/14 → 84-14x = 10x → x = 3.5
DC = 3.5 सेमी

उदाहरण 2: दो समरूप त्रिभुजों की भुजाओं का अनुपात 3:5 है। क्षेत्रफलों का अनुपात = (3/5)² = 9:25

4.6 त्रिकोणमिति का परिचय

📦 त्रिकोणमिति के मूल सूत्र
sinθ = लंब/कर्ण, cosθ = आधार/कर्ण, tanθ = लंब/आधार
cosecθ = 1/sinθ, secθ = 1/cosθ, cotθ = 1/tanθ
sin(90°-θ) = cosθ, cos(90°-θ) = sinθ

सर्वसमिकाएँ:
sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = cosec²θ

हल किए गए उदाहरण

उदाहरण 1: (sin30° + cos30°) - (sin60° + cos60°) = (1/2+√3/2)-(√3/2+1/2) = 0

उदाहरण 2: sin²90° - tan²45° = 1 - 1 = 0

उदाहरण 3: सिद्ध करें: (1 + cot²θ) sin²θ = 1
हल: cosec²θ · sin²θ = (1/sin²θ)·sin²θ = 1 ✓

4.7 वृत्त

📦 वृत्त के सूत्र
स्पर्श रेखा उस बिंदु पर त्रिज्या के लंबवत होती है।
बाह्य बिंदु से दो स्पर्श रेखाओं की लंबाई बराबर होती है।
स्पर्श रेखा की लंबाई = √(d² - r²)

4.10 निर्देशांक ज्यामिति

📦 निर्देशांक ज्यामिति के सूत्र
